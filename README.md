# flyrank-capstone-image-relevance

AI Image Understanding & Content Matching Engine — FlyRank Backend Track capstone.

Understand an image library through a vision model, embed captions and post text
into one semantic space, and match the right image to the right blog post — with a
mismatch guard that refuses wrong pairings with an explanation instead of guessing.

Status: **planning** — route being charted in `.planning/capstone-map/MAP.md`.

Stack (locked): Node.js + Express · Gemini Flash free tier (vision + embeddings) ·
PostgreSQL via Docker · Zod schema validation · $0, no credit card ever.
